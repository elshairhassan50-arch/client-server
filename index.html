🧩 تشريح الـ API: كيف يحدد الواجهة الخلفية (Backend) المسارات؟

لكل موقع أو تطبيق API خاص به يصممه مبرمج الواجهة الخلفية (Backend). يتكون الـ API من نقط انتهاء يطلق عليها Endpoints (أو Routes)، وتكون كل نقطة مخصصة لوظيفة معينة:

POST /api/login
مخصص لتسجيل الدخول: يرسل العميل الاسم وكلمة المرور في الـ Payload ليتحقق منها الخادم.
GET /api/products
مخصص لعرض المنتجات: يطلب العميل قائمة المنتجات والأسعار ليعرضها للمستخدم.
POST /api/posts/101/like
مخصص لتفاعل الإعجاب: يبعث العميل رقم المستخدم ورقم البوست لتحديث عدد اللايكات.

🧪 تطبيق عملي للطلاب: ماذا يحدث في الكواليس عند الضغط على "لايك"؟

📚 مصطلحات الدرس المعتمدة من الكتاب

العميل (Client) الجانب الطالب

برنامج أو جهاز يرسل طلبًا إلى خدمة أخرى؛ ومن أمثلته متصفح الويب وتطبيق الهاتف.

الخادم (Server) الجانب المعالج

الجانب الذي يستقبل الطلبات من العملاء، ويعالجها، ويعيد الاستجابات والبيانات المطلوبة.

بروتوكول HTTP النص التشعبي

بروتوكول يُستخدم لتبادل الرسائل والطلبات والاستجابات بين العميل والخادم على الويب.

بروتوكول HTTPS الاتصال الآمن

استخدام HTTP عبر اتصال آمن يسمى TLS. يحمي سرية الاتصال وسالمته ومصادقة الخادم لمنع التجسس.

الـ API واجهة البرمجيات

واجهة أو عقد محدد بـ مجموعة قواعد واضحة تسمح لبرنامج بطلب بيانات أو وظائف من برنامج آخر.

صيغة JSON تبادل البيانات

صيغة نصية شائعة لتمثيل وتبادل البيانات المهيكلة باستخدام كائنات ومصفوفات وقيم بسيطة.

⚖️ مقارنة توضيحية للطلاب: ما الفرق بين الـ HTTP والـ API؟

وجه المقارنة بروتوكول الـ HTTP واجهة الـ API
المفهوم بروتوكول وطريقة نقل الرسائل عبر الشبكة. مجموعة قواعد وعقد يحدد كيف تطلب البيانات وتستقبلها.
التشبيه الواقعي **وسيلة النقل** (مثل الشاحنة أو الطريق الذي ينقل الطرد). **الجرسون / العقد** (الذي يحدد ماذا يمكنك أن تطلب وكيف يأتيك الطلب).
الوظيفة يضمن وصول الرسالة من العميل إلى الخادم والعكس بسلام. يحدد شكل الرسالة، الموارد المتاحة، والعمليات (GET, POST).

💡 توقّف وفكّر: لماذا يجب أن تستخدم صفحة تسجيل الدخول HTTPS بدلاً من HTTP؟

لأن صفحة تسجيل الدخول تحتوي بيانات حساسة (مثل كلمة المرور). باستخدام HTTPS المدعوم بتشفير TLS، يتم تشفير البيانات قبل نقلها فلا يستطيع أي متجسس على الشبكة قراءتها أو تعديلها أثناء النقل.
